## 读者问题

1. `Engine.index()` 到 `InternalEngine.index()` 的完整路径是什么？

3. `canOptimizeAddDocument()` 怎么利用 autoGeneratedIdTimestamp 检测重试？
4. `LiveVersionMap` 怎么管理内存版本？

## 主结论

InternalEngine 的写入是 **plan-and-execute 模式**：`planIndexingAsPrimary()`（L1314）先判断策略，再 `indexIntoLucene()`（L1384）执行。`canOptimizeAddDocument()`（L1059）利用 autoGeneratedIdTimestamp 检测重试→直接用 `addDocument` 而非 `updateDocument`。
