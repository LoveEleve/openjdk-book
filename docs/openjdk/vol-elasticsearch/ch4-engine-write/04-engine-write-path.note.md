# vol-elasticsearch E-1a Engine 写入路径 — note

## 本篇主张

- InternalEngine 的写入是 **plan-and-execute 模式**：`planIndexingAsPrimary()`（L1314）决定策略，`indexIntoLucene()`（L1384）执行。
- `canOptimizeAddDocument()`（L1059）利用 autoGeneratedIdTimestamp 检测重试，对 append-only 场景跳过版本查找。
- `IndexingStrategy`（L1483）是 record 类，包含 `indexIntoLucene/appStaleOpToLucene/useLuceneUpdateDocument` 标志。
- `LiveVersionMap` 管理内存版本，`readLock` 允许多个 index 并发。
