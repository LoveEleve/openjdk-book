### 发现并修正的 1 个问题

**R-2 RLock Lua 锁脚本内容错误**：正文初稿用了经典版脚本（`hset` + 独立 `hincrby` 两个分支），实际 `RedissonLock.java:217-227` 是**合并分支**：

```lua
if ((redis.call('exists', KEYS[1]) == 0)
        or (redis.call('hexists', KEYS[1], ARGV[2]) == 1)) then
    redis.call('hincrby', KEYS[1], ARGV[2], 1);
    redis.call('pexpire', KEYS[1], ARGV[1]);
    return nil;
end;
return redis.call('pttl', KEYS[1]);
```

`exists==0`（锁不存在）或 `hexists==1`（可重入）进**同一分支**直接 `hincrby`，无独立 `hset` 分支。已修正正文 + note。
