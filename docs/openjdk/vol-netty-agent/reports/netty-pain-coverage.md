## 二、相对 low 版章纲的改进

low 版问题：
- 教程味过重
- 全部 B 深度
- 过早进入案例和 HTTP 层
- 横切机制几乎不可见
- 没有风险、演进、迁移、自测结构

当前改进：
- 主线机制提升为卷一/卷二核心
- A 深度章节显式出现
- 横切机制单独成卷/专题
- 风险边界、演进、迁移、自测都进入书结构
- HTTP 等外围协议下放到较晚位置，并明确是外围层

## 三、仍然不足的地方

1. 还没有真正从源码自动长出这一版大纲，目前仍是规划式人工评审产物。
2. 类比轨、考点地图、自测点还没有被逐章自动展开。
3. R1 入口问题和 A5 入口锚定偏差还没有在 Netty 无基线运行中被真正验证。
4. 当前 pain coverage 是结构评审，不是执行后基于真实章节的回证。

## 四、结论

这版无基线 Netty 章纲已经明显优于最初 low 版：
- 更接近源码学习书，而不是入门教程目录；
- 已经把 Netty 真正难的主线和横切机制显式拉出来；
- 也开始覆盖“为什么学不会源码”的核心痛点。

但它还没有完成最后一步：
> 从“评审后强大”变成“Agent 自动生成也能强大”。

这需要继续把 M16.0 主链彻底接到 spec 生成和真实 Netty 运行中。
