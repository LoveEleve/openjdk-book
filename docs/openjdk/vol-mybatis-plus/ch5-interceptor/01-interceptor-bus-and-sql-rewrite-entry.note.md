# MP-5 插件总线与 SQL 改写入口 — note

## 本篇主张

- MP 的运行时增强不是一堆散插件，而是 `MybatisPlusInterceptor + InnerInterceptor` 统一插件总线。
- `PluginUtils` 不是杂项工具，而是增强家族统一操作 `StatementHandler / BoundSql` 的访问协议层。
- 分页只是样板，不是本篇真正主角；真正主角是“总线 + 位点 + 访问器”这套增强协议。

## 本篇边界

- 不展开每个内置增强的全部算法细节。
- 不把分页、租户、权限、安全分别写成并列主线。
- 只在需要时点到 ignore 机制和 BoundSql 改写副作用。

## 下篇桥接

- `MP-6` 将把分页、乐观锁、自动填充、逻辑删除、租户、权限、安全这些增强家族分别收束成专题组。
