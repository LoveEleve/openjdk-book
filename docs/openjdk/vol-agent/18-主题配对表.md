# 主题配对表

> 用途：把理论主线、论文主线、实验主线和源码映射线绑成同一套主题，不各自独立生长。
> 原则：每个核心主题都应同时产出“理论正文”“论文精读”“最小实验”和“源码映射”四样东西，但可以分批交付。

---

## 一、配对规则

```text
理论正文 1 篇
  → 配套论文精读 1 篇
  → 配套最小实验 1 篇
  → 配套真实源码映射 1 节（在正文或独立笔记中）
```

同一主题的四样东西不一定同时写，但必须成对规划，不能写了理论不去补论文，也不读了论文不回接工程。

## 三、说明

- 论文精读列为主要线，不是每篇理论正文都有独立论文；有些论文（如 Attention Is All You Need、ReAct、RAG）同时服务多个理论主题，但精读只写一次。
- 实验列标注为“可运行”实验，不是理论推导。
- 源码映射列优先指向已有 `vol-agent` 五项目源码分析，不造新项目。
- 后 30 号以后的配对（如分布式训练、Stable Diffusion、多模态等）不在当前卷第一版计划内，属后续扩展。
