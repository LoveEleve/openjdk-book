> 用途：明确卷 AI 第一阶段的写作顺序、前置依赖、交付标准和工作量。

## 一、第一批目标

第一批不追求覆盖所有领域，只追求让读者完成一件事：

因此第一批全部围绕 `00-prerequisites → 01-foundations → 02-transformer` 展开。

## 三、为什么是这个顺序

- `00-prerequisites` 让零基础读者先建立“程序、数据、函数、模型、学习”的完整语言，避免直接掉进数学符号。
- `01-foundations` 只补神经网络前向/反向和语言建模损失所需的最小数学。
- `02-transformer` 让读者第一次看到“token → embedding → attention → causal mask → block → logits → sampling”完整链路。
- 论文和实验穿插在第 13~16 篇，而不是等整卷读完再补，保证“会讲也会跑”。

---

## 四、交付标准

每篇正文必须满足：

1. 有明确问题，不是概念标题；
2. 有最小前置知识；
3. 有“直觉方案为什么失败”；
4. 有正式机制对象、状态、数据流、复杂度；
5. 有最小实现或伪代码；
6. 有论文/实验/源码映射（至少一项）；
7. 有与下一篇的依赖关系；
8. 没有把推测写成事实。

每个实验必须满足：

1. 目标；
2. 输入与假设；
3. 最小实现；
4. 结果与指标；
5. 失败样本/边界；
6. 能证明什么，不能证明什么。

## 五、预估工作量

- 12 篇理论正文（每篇约 800~1200 行内容）
- 1 篇论文精读（Attention Is All You Need）
- 3 个最小实验
- 1 份总蓝图 + 1 份主题配对表（本轮已交付）

第一批完成后，读者应能：
- 从 token id 追踪到 logits；
- 手动解释 mask、shape、复杂度；
- 用最小代码验证 Attention 和 decoding。
