# AI / 大模型 / Agent 理论卷覆盖矩阵与收口标准

> 用途：像 `VOL-02-COVERAGE-MATRIX.md` 一样，明确本卷覆盖什么、不覆盖什么、每个阶段达到什么深度，以及何时可以称为阶段性完成。

---

## 一、覆盖等级

- **核心**：有连续文章、公式、最小实验和失败模式；可以作为该主题的主要入口。
- **深入**：有论文、实现细节、复杂度、数值/系统边界和源码映射。
- **入口**：建立概念和调用链，后续仍需专门专题。
- **桥接**：用于连接两个主题，不承担完整理论覆盖。
- **范围外**：明确不在本卷当前主线内。

## 五、明确不在当前主线中的内容

以下内容不是遗漏，而是主动控制范围：

- 从零训练数十亿参数模型的完整集群运维；
- CUDA/PTX/NCCL 的全部底层实现；
- 所有商业模型的 provider 特殊行为；
- 完整的数学分析、测度论和优化理论教材；
- 所有多 Agent 框架的 API 目录；
- 医疗、金融、法律领域的具体合规结论；
- 把某个 Agent 项目的当前实现直接宣传为通用理论。

它们可以在后续建立独立专题，但不应让第一版主线失去依赖顺序。

---

## 六、一句话结论

> **本卷的完成标准不是“覆盖了多少 AI 名词”，而是完成五次升级：模型可解释、模型可训练、模型可推理、Agent 可执行、Agent 可长期可靠运行。**
