# 零基础阅读协议与学习进度卡

> 用途：防止读者从“什么是数据”直接跳到 Transformer，定义每一层进入下一层前必须具备的知识和可验证产物。

---

## 一、阅读协议

### 第一次阅读：只追主线

第一次读一篇文章，只回答：

1. 它要解决什么问题？
2. 输入是什么？
3. 输出是什么？
4. 中间发生了哪三步？
5. 如果没有这个机制会失败在哪里？

第一次不要追：
- 所有公式证明；
- 所有工程优化；
- 所有论文引用；
- 所有源码分支。

### 第二次阅读：补机制

第二次再补：
- 每个对象的定义；
- 每个公式的 shape；
- 每个状态转换；
- 时间/空间复杂度；
- 最小代码实现。

### 第三次阅读：做验证

第三次必须动手：
- 修改一个输入；
- 观察一个中间值；
- 构造一个失败样本；
- 对比一个替代方案；
- 记录结论成立的边界。

### 第四次阅读：接入系统

最后回答：
- 这个机制在真实模型哪里出现？
- 在 Agent Runtime 哪里出现？
- 它会产生什么成本和副作用？
- 系统如何观测、恢复或拒绝它？

## 二、零基础依赖门

### Gate 0：程序语言

必须会：
- 变量、函数、条件、循环；
- 列表、字典、文件；
- 异常和模块；
- 运行 Python 脚本。

对应章节：`00-prerequisites/00-4`。

### Gate 1：数据与函数

必须会：
- 数据可以被编码；
- 函数把输入映射成输出；
- 算法是有限步骤；
- 复杂度描述资源成本。

对应章节：`00-prerequisites/00-2`、`00-3`。

### Gate 2：模型与学习

必须会：
- 样本、特征、标签、目标；
- 参数化模型；
- 训练集与测试集；
- 预测、误差、泛化。

对应章节：`00-prerequisites/00-5` 到 `00-11`。

### Gate 3：数学与神经网络

必须会：
- 向量和矩阵的基本运算；
- 概率和交叉熵直觉；
- 函数复合与梯度直觉；
- 一个两层网络的前向和反向。

对应章节：`01-foundations/`。

### Gate 4：Transformer

必须会：
- token id、embedding、shape；
- Q/K/V；
- mask；
- softmax；
- residual 和 normalization。

对应目录：`02-transformer/`。

### Gate 5：语言模型与推理

必须会：
- causal language modeling；
- logits 与概率；
- sampling；
- prefill/decode；
- KV Cache。

对应目录：`03-model-training/`、`04-inference/`。

### Gate 6：Agent

必须会：
- 模型调用不是完整任务；
- tool call/result 是协议；
- loop 有状态和停止条件；
- 外部动作需要授权和结果验证。

对应目录：`05-agent-foundations/`。

### Gate 7：Runtime

必须会：
- durable truth；
- session/history/projection；
- permission/sandbox/lease；
- recovery/evidence/evaluator。

对应目录：`06-agent-runtime/` 和五个项目子目录。

## 三、每层必须产出的东西

| 层 | 最小产物 | 通过标准 |
|---|---|---|
| 00 前置 | 规则程序 + 数据统计脚本 | 能解释程序、数据、函数、模型的区别 |
| 01 数学 | MLP + 数值梯度检查 | 能解释 loss、gradient、update |
| 02 Transformer | Self-Attention + mask 可视化 | 能从 token 追到 logits |
| 03 训练 | tiny LM 或 toy SFT/DPO | 能解释训练目标和数据流 |
| 04 推理 | KV Cache + sampling benchmark | 能解释速度、显存和质量取舍 |
| 05 Agent | Tool Loop + 错误回注 + stop | 能画出 Agent 状态与行动闭环 |
| 06 Runtime | event/session/recovery mini system | 能解释真相层、上下文层、恢复边界 |
| 07 论文 | 论文卡片 + 复现实验 | 能区分论文结论和迁移判断 |
| 08 实验 | 可重复实验目录和报告 | 输入、指标、失败样本可复核 |
| 09 安全 | hostile fixtures + trajectory report | 能证明系统拒绝越权并记录原因 |

## 四、遇到看不懂的概念怎么办？

不要直接搜索更复杂的解释，按以下顺序退回：

1. 这个概念的输入和输出是什么？
2. 输入输出是不是数据结构问题？
3. 是否缺少函数/概率/向量前置？
4. 是否缺少训练阶段和推理阶段区分？
5. 是否缺少一个具体数字例子？
6. 是否缺少失败方案对照？
7. 是否把模型能力和 runtime 能力混在一起？

如果回答不了，回退一层，而不是继续向后跳。

## 一句话结论

> **真正的零基础路线不是降低内容深度，而是把每次跨越拆成一个可验证的台阶，让读者知道自己为什么能进入下一层。**
