# 论文总索引与精读路线

> 用途：为卷 AI 提供一份**可验证公开链接**的论文与技术报告索引。
> 原则：优先使用 arXiv、官方技术报告页、官方项目主页；不使用来路不明的二手 PDF 链接；只收当前能确认公开可访问的资料。

---

## 一、使用方式

读论文不要按热度乱跳，先按四条主线进入：

1. **模型原理主线**：Transformer、预训练、规模化
2. **训练与对齐主线**：SFT、RLHF、DPO、LoRA、QLoRA、MoE
3. **Agent 与工具主线**：ReAct、Toolformer、Reflection、RAG、评测
4. **国产/近年代表模型主线**：DeepSeek、ChatGLM 等公开技术报告

每篇条目包含：
- 主题标签
- 推荐阶段
- 推荐前置
- 公开链接
- 为什么值得读

## 二、模型原理主线（必读）

### 1. Attention Is All You Need
- 标签：Transformer / Attention / Seq2Seq
- 推荐阶段：Phase 2
- 前置：向量、矩阵、softmax、序列建模直觉
- 公开链接：<https://arxiv.org/abs/1706.03762>
- PDF：<https://arxiv.org/pdf/1706.03762>
- 价值：所有后续 LLM/Agent 系统的基础算子都从这里分叉出来。

### 2. BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding
- 标签：预训练 / Encoder / 表示学习
- 推荐阶段：Phase 3
- 前置：Transformer 基本结构、预训练概念
- 公开链接：<https://arxiv.org/abs/1810.04805>
- PDF：<https://arxiv.org/pdf/1810.04805>
- 价值：帮助读者理解“预训练模型”不只是一种生成器，也可以是一种通用表示器。

### 3. Language Models are Few-Shot Learners
- 标签：GPT-3 / In-Context Learning / Scaling
- 推荐阶段：Phase 3
- 前置：Causal LM、prompt、上下文窗口
- 公开链接：<https://arxiv.org/abs/2005.14165>
- PDF：<https://arxiv.org/pdf/2005.14165>
- 价值：把“大模型为什么突然会做事”正式推到台前。

## 三、训练与对齐主线（必读）

### 4. Training language models to follow instructions with human feedback
- 标签：InstructGPT / RLHF / 对齐
- 推荐阶段：Phase 3
- 前置：预训练、SFT、奖励与偏好基本概念
- 公开链接：<https://arxiv.org/abs/2203.02155>
- PDF：<https://arxiv.org/pdf/2203.02155>
- 价值：解释“会续写”如何变成“会按意图回答”。

### 5. LoRA: Low-Rank Adaptation of Large Language Models
- 标签：LoRA / PEFT / 微调
- 推荐阶段：Phase 3
- 前置：矩阵分解、Transformer 线性层、微调目标
- 公开链接：<https://arxiv.org/abs/2106.09685>
- PDF：<https://arxiv.org/pdf/2106.09685>
- 价值：最重要的参数高效微调论文之一。

### 6. QLoRA: Efficient Finetuning of Quantized LLMs
- 标签：QLoRA / 量化 / 单机微调
- 推荐阶段：Phase 3 → 4
- 前置：LoRA、量化、显存预算
- 公开链接：<https://arxiv.org/abs/2305.14314>
- PDF：<https://arxiv.org/pdf/2305.14314>
- 价值：把“可训练”与“资源受限”联系起来。

### 7. Direct Preference Optimization
- 标签：DPO / 偏好优化 / 对齐
- 推荐阶段：Phase 3
- 前置：偏好数据、策略/奖励基本概念
- 公开链接：<https://arxiv.org/abs/2305.18290>
- PDF：<https://arxiv.org/pdf/2305.18290>
- 价值：如果后续你要讲现代对齐，DPO 基本绕不过去。
- 备注：当前仅在课程规划中列为必补论文，建议后续正式加入 `../07-papers/README.md`。

### 8. DeepSeekMoE: Towards Ultimate Expert Specialization in Mixture-of-Experts Language Models
- 标签：MoE / 稀疏专家 / DeepSeek
- 推荐阶段：Phase 3
- 前置：Transformer、Routing、稀疏激活、训练成本
- 公开链接：<https://arxiv.org/abs/2401.06066>
- PDF：<https://arxiv.org/pdf/2401.06066>
- 价值：国产公开大模型里，MoE 设计最值得细讲的一篇之一。

### 9. DeepSeek-V2: A Strong, Economical, and Efficient Mixture-of-Experts Language Model
- 标签：DeepSeek / MLA / MoE / 长上下文 / 推理效率
- 推荐阶段：Phase 3 → 4
- 前置：MoE、KV Cache、注意力与推理成本
- 公开链接：<https://arxiv.org/abs/2405.04434>
- PDF：<https://arxiv.org/pdf/2405.04434>
- 价值：兼有训练、架构和推理效率，适合卷 AI 做代表模型专题。

### 10. ChatGLM: A Family of Large Language Models from GLM-130B to GLM-4 All Tools
- 标签：ChatGLM / 中文模型 / Tool Use / 家族技术报告
- 推荐阶段：Phase 3 → 5
- 前置：预训练、对齐、工具调用基本概念
- 公开链接：<https://arxiv.org/abs/2406.12793>
- PDF：<https://arxiv.org/pdf/2406.12793>
- 价值：适合讲“国产模型如何从底座走到 All Tools”。

### 11. DeepSeek-Coder: When the Large Language Model Meets Programming
- 标签：代码模型 / DeepSeek / Fill-in-the-Blank
- 推荐阶段：Phase 3 → 5
- 前置：语言模型、代码任务、补全/插补
- 公开链接：<https://arxiv.org/abs/2401.14196>
- PDF：<https://arxiv.org/pdf/2401.14196>
- 价值：如果后面要讲 coding agent，这是必须接的一篇。

## 四、推理与系统主线（必读）

### 12. FlashAttention
- 标签：Attention 优化 / IO-aware / 推理与训练效率
- 推荐阶段：Phase 4
- 前置：attention 计算、显存读写、矩阵乘法
- 公开链接：<https://arxiv.org/abs/2205.14135>
- PDF：<https://arxiv.org/pdf/2205.14135>
- 价值：解释 Attention 为什么慢，以及“算得快”常常是 IO 问题不是 FLOPs 问题。

### 13. Efficient Streaming Language Models with Attention Sinks
- 标签：长上下文 / StreamingLLM / KV Cache
- 推荐阶段：Phase 4
- 前置：KV Cache、窗口注意力、长文本推理
- 公开链接：<https://arxiv.org/abs/2309.17453>
- PDF：<https://arxiv.org/pdf/2309.17453>
- 价值：适合讲“为什么只保留最近窗口不够，为什么还要 sink token”。

### 14. Mistral 7B
- 标签：GQA / SWA / 高效开源模型
- 推荐阶段：Phase 4
- 前置：Attention、KV Cache、长上下文效率
- 公开链接：<https://arxiv.org/abs/2310.06825>
- PDF：<https://arxiv.org/pdf/2310.06825>
- 价值：用一篇模型报告把 GQA、滑动窗口和开源模型效率讲清楚。

## 五、Agent 与工具主线（必读）

## 七、暂不收录或谨慎收录的资料

以下资料当前不放进正式索引主表：

1. **只有产品页面、没有明确技术报告的页面**
   - 例如仅有聊天产品首页、营销页、无清晰论文/报告正文的站点。

2. **撤稿、无 PDF 或证据质量存疑的论文**
   - 例如已撤稿或无法确认关键结论来源的条目。

3. **二手博客、转载 PDF、网盘链接**
   - 即使能打开，也不作为主入口。
