# 5 Agent 项目横向对比总锚点

> 用途：对比 OpenCode / Reasonix / Pi / Hermes / dsh 五个项目的核心差异。

---

## 一、一句话定位

| 项目 | 一句话定位 |
|------|-----------|
| **OpenCode** | 现代 Agent runtime 的完整工程化版本 |
| **Reasonix** | 受控制器驱动的长跑任务操作系统 |
| **Pi** | 共享运行时 + 多形态外壳 + 双层能力系统 |
| **Hermes** | 多平台长期代理 + 学习闭环 + 账本系统 |
| **dsh** | 一切皆插件的 Agent 框架，无特权核心 |

---

## 二、10 个对比维度

| 对比维度 | OpenCode | Reasonix | Pi | Hermes | dsh |
|----------|----------|----------|-----|--------|-----|
| **执行骨架** | SessionRunner + RunCoordinator | Controller + RunLoop | Agent Loop + AgentSession | AIAgent + GatewayRunner | Phase 状态机 + 事件瀑布 |
| **上下文工程** | SystemContext + Epoch | 缓存优先 + 固定前缀 | 分支摘要 + 三段式 | Prompt Cache 神圣 | 会话日志 = 上下文源 |
| **完成判定** | 无独立 evaluator | Goaleval fail-closed | — | GoalJudge + 守卫族 | 插件化 |
| **知识系统** | plugin / skills | subject 冲突 | facts 表 | 学习闭环 + curator | 能力缝 |
| **持久化** | SQLite / WAL | checkpoint | JSONL 树 | delivery / lifecycle 账本 | 双后端 |
| **平台化** | MCP / ACP / SDK | 控制器 | 多形态共享内核 | 多平台适配器 | 一切皆插件 |
| **边界控制** | Permission | WorkspaceLease | 工具组合预设 | SecretScope / SelfRepoGuard | 能力缝 |
| **失败语义** | 截断全失败 | 分类学 | 错误结果模式 | 23 类分类学 | 测试契约 |
| **架构哲学** | 控制面外化 | 单一控制器 | 共享运行时 | 多平台长期代理 | 一切皆插件 |
| **学习曲线** | 中 | 高 | 中 | 高 | 高 |

---

## 三、5 个项目的互补关系

- **OpenCode**：最完整的现代 Agent runtime 样本
- **Reasonix**：最完整的受控任务系统样本
- **Pi**：最完整的共享运行时 + 多形态样本
- **Hermes**：最完整的长期代理 + 学习闭环样本
- **dsh**：最完整的插件化 Agent 框架样本

---

## 四、一句话结论

5 个项目拼在一起，基本覆盖了 Agent 系统设计的全部核心问题：执行、上下文、完成判定、知识、持久化、平台化、边界控制、失败语义和架构哲学。
