## 三、直觉方案为什么不够好

很多人第一次接触"多层神经网络"时，直觉是：

> 神经网络就是有很多层，每层有很多神经元，很像人脑。

这个直觉有两个问题。

**问题 1：太像人脑反而不好**
"像人脑"这个比喻会让人误以为神经网络有"意识"或"理解"能力。
实际上神经网络只是一个巨大的参数化函数组合。

**问题 2：忽略了"向量"这个核心抽象**
神经网络不是"一个数字进去，一个数字出来"。
它是一批数字同时进去，一批数字同时出来。

所以正确的理解方式应该是：

> **神经网络 = 把输入向量，通过多层线性变换 + 非线性激活，变成输出向量。**

## 四、正式机制

### 1. 向量：一组数字打包在一起

向量 = 有序排列的一列数字。

```text
[3.0, 1.2, 0.5, -0.3]
```

- 向量的"长度"叫维度
- 上面这个向量是 4 维

在神经网络里，几乎所有东西都是向量：
- 输入文本 → 向量
- 中间表示 → 向量
- 输出概率分布 → 向量

### 2. 矩阵：向量排成表格

矩阵 = 多行多列的数字表格。

形状是 `(行数, 列数)`。

例如一个 2 行 3 列的矩阵：

```text
[[1, 2, 3],
 [4, 5, 6]]
```

形状 = `(2, 3)`

矩阵最重要的用途是：**把向量从一种表示变换成另一种表示。**

### 3. 线性变换：矩阵 × 向量

矩阵和向量相乘，是把向量"转换"成另一个向量。

```text
矩阵 (2×3) × 向量 (3) → 向量 (2)
```

具体计算：

```text
[[1, 2, 3],     [10]      [1×10 + 2× 5 + 3× 2]     [26]
 [4, 5, 6]]  ×  [ 5]  =  [4×10 + 5× 5 + 6× 2]  =  [77]
                 [ 2]
```

这就是线性变换的核心：矩阵的每一行，和向量做点乘，产生一个输出值。

### 4. 偏置：平移向量

光有线性变换还不够，还需要一个"平移"。

```text
y = W · x + b
```

- $W$ 是权重矩阵（weight matrix）
- $x$ 是输入向量
- $b$ 是偏置向量（bias vector）

这就是**线性层**的核心公式。

### 5. 非线性激活函数：为什么要加它

如果只有线性层，不管叠多少层，最终都等价于一个线性变换。

这意味着：

> 没有非线性激活，再深的网络也只能表达线性关系。

但现实世界的数据几乎都是非线性的。

所以必须在线性变换之后，加一个**非线性激活函数**。

最常见的激活函数之一是 ReLU：

```text
ReLU(x) = max(0, x)
```

- 负数 → 0
- 正数 → 不变

### 6. 单层网络 = 线性变换 + 激活

```text
h = ReLU(W · x + b)
```

- $x$：输入向量
- $W$：权重矩阵
- $b$：偏置向量
- $W·x + b$：线性变换（线性层）
- ReLU：非线性激活

### 7. 多层网络 = 层的组合

```text
h1 = ReLU(W1 · x + b1)
h2 = ReLU(W2 · h1 + b2)
y  = W3 · h2 + b3
```

- 第一层：输入向量 x → 中间向量 h1
- 第二层：h1 → h2
- 第三层：h2 → 输出 y

每层都有自己的参数（W 和 b），它们都是训练中要调整的参数。

这就是"多层感知机（MLP）"。

后面讲 Transformer 时，你会反复看到这个结构。

## 五、最小实现 / 伪代码

### 1. 矩阵 × 向量

```python
import numpy as np

# 2×3 矩阵
W = np.array([[1, 2, 3],
              [4, 5, 6]])
# 3 维向量
x = np.array([10, 5, 2])

y = W @ x  # 矩阵 × 向量
print(y)   # [26, 77]
```

### 2. 单层网络

```python
def relu(x):
    return np.maximum(0, x)

def linear_layer(W, b, x):
    return relu(W @ x + b)

W = np.array([[0.5, -0.2],
              [0.3,  0.8]])
b = np.array([0.1, -0.1])
x = np.array([1.0, 2.0])

h = linear_layer(W, b, x)
print(h)  # 输出一个 2 维向量
```

### 3. 两层网络

```python
def two_layer_net(W1, b1, W2, b2, x):
    h = relu(W1 @ x + b1)    # 第一层
    y = W2 @ h + b2           # 第二层（无激活）
    return y

# 形状：输入 4 维 → 隐藏层 3 维 → 输出 2 维
W1 = np.random.randn(3, 4)
b1 = np.random.randn(3)
W2 = np.random.randn(2, 3)
b2 = np.random.randn(2)

x = np.array([1.0, 2.0, 3.0, 4.0])
y = two_layer_net(W1, b1, W2, b2, x)
print(y)  # 输出一个 2 维向量
```

这就是一个完整的前向计算。

## 六、复杂度与边界

1. **矩阵乘法是计算瓶颈**
   - 神经网络 90% 以上的计算量在矩阵乘法上
   - 后面 FlashAttention 等优化，本质上都在加速矩阵运算

2. **参数数量 = 矩阵大小相加**
   - 如果输入 1000 维，输出 500 维，那么这一层就有 1000×500 + 500 = 500,500 个参数
   - 这解释了为什么大模型参数动辄几百亿

3. **非线性激活不可或缺**
   - 去掉激活，多层网络就退化为单层
   - 不同激活函数（ReLU、GELU、Sigmoid）影响训练速度和效果

4. **向量长度必须一致**
   - 矩阵的列数必须等于输入向量维度
   - 矩阵的行数决定输出向量维度
   - 形状不匹配是神经网络最常见的 bug

## 七、论文与真实系统映射

这一章没有专门论文，但所有后续论文都建立在它之上。

在真实系统里：
- 每一层 W 就是模型的"权重"
- 权重文件（如 .pth、.safetensors）存的就是这些矩阵
- 训练就是不断调整这些矩阵里的数值

如果你去看真实 Agent Runtime：
- 模型调用本质上就是一次巨大的前向计算
- 工具调用参数的结构化解析，本质上也是把 JSON 转成向量再处理

## 一句话结论

> **神经网络本质就是一个参数化函数组合：输入向量经过多层线性变换和激活，变成输出向量。权重矩阵 W 和偏置向量 b 就是参数，训练就是在调整它们。**
