# 梯度与反向传播：误差如何传回每一层参数

> 前置：`01-向量矩阵与神经网络.md`
> 本篇任务：理解梯度下降和反向传播，知道"参数更新"这件事到底是怎么发生的。

---

## 一、这一章真正的问题

上一章我们建立了前向计算：

```text
输入向量 → 线性变换 → 激活 → 下一层 → 输出向量
```

但输出向量和"正确答案"之间通常有差距。

这个差距就是 **误差（error）** 或 **损失（loss）**。

这一章要回答：

1. 损失怎么衡量？
2. 误差怎么"传回去"更新每一层的参数？
3. 为什么链式法则是反向传播的基础？
4. 梯度下降到底在做什么？

---

## 二、最小前置知识

- 理解前向计算：矩阵 × 向量 + 激活
- 理解"误差 = 输出 - 目标"
- 理解函数组合：$f(g(x))$

---

## 三、直觉方案为什么不够好

很多人第一次接触"怎么调参数"时，直觉是：

> 每个参数都试一下，看调大还是调小能让误差变小。

这个直觉在参数只有 1 个的时候成立，但神经网络有成千上万个参数，逐个试不现实。

所以必须有一种方法，能一次算出来：

> **每个参数该往哪个方向调、调多少。**

这就是"梯度"要做的事。

---

## 四、正式机制

### 1. 损失函数：衡量误差

损失函数 = 一个函数，输入是"模型输出"和"正确答案"，输出是一个数字表示"差多少"。

最常见的损失之一是均方误差（MSE）：

```text
loss = (y_pred - y_true)²
```

- 如果 y_pred 接近 y_true → loss 接近 0
- 如果 y_pred 远离 y_true → loss 变大

### 2. 梯度：往哪个方向调能让损失变小

梯度 = 对损失函数求每个参数的偏导数。

直觉理解：

站在一个山上，你要找下山的路。
- 梯度告诉你：哪个方向是下坡、坡度有多陡
- 你往梯度相反的方向走一步 → 位置更低 → 损失更小

数学上：

```text
w_new = w_old - learning_rate × gradient
```

- `gradient` 是损失对 w 的梯度
- `learning_rate` 是步长，控制每次走多大
- 减号是因为我们想"下坡"

### 3. 链式法则：梯度如何穿过复合函数

神经网络由多层函数组合而成：

```text
loss = L(y(W2 · h(W1 · x)))
```

这是一个复合函数：L ∘ y ∘ h ∘ linear。

要求损失对 W1 的梯度，就需要用**链式法则**：

```text
∂loss/∂W1 = (∂loss/∂y) × (∂y/∂h) × (∂h/∂W1)
```

也就是：从损失开始，一层层往回传。

### 4. 反向传播：从输出到输入的梯度传递

反向传播就是链式法则在神经网络里的具体实现：

```text
前向：x → 层1 → 层2 → 层3 → 输出 → loss
反向：loss → 层3的梯度 → 层2的梯度 → 层1的梯度
```

每一步只做一件事：
1. 收到上一层传来的梯度
2. 计算"当前层的参数对损失的影响"
3. 把梯度继续往回传

这样，每一层都能得到"自己该往哪个方向调参数"。

### 5. 学习率：步长为什么要控制

梯度告诉方向，但没告诉"走多远"。

- 学习率太大 → 跳过最优位置，可能震荡
- 学习率太小 → 训练太慢，可能卡在局部最低点

所以学习率是一个需要精心调节的超参数。

## 五、最小实现 / 伪代码

### 1. 单个参数的手动梯度

```python
# 模型：y = w * x
# 损失：MSE
# 目标：y_true = 6, x = 3

x = 3.0
y_true = 6.0
w = 0.0          # 初始参数
lr = 0.01        # 学习率

for step in range(20):
    y_pred = w * x
    loss = (y_pred - y_true) ** 2
    gradient = 2 * (y_pred - y_true) * x  # 对 w 求导
    w = w - lr * gradient

    print(f"step {step}: w={w:.3f}, loss={loss:.3f}")
```

这里的 `gradient = 2 * (y_pred - y_true) * x` 就是链式法则的结果：
- `(y_pred - y_true)²` 对外层求导 → `2 * (y_pred - y_true)`
- `w * x` 对内层求导 → `x`
- 两者相乘 → 梯度

### 2. 两层网络的反向传播示意

```python
import numpy as np

# 前向
x = np.array([1.0, 2.0])
W1 = np.array([[0.5, 0.3], [0.2, 0.8]])
b1 = np.array([0.1, 0.1])
W2 = np.array([[0.4, 0.6]])
b2 = np.array([0.0])

# 第一层
h = np.maximum(0, W1 @ x + b1)     # ReLU 激活
# 第二层
y_pred = W2 @ h + b2                # 线性输出

# 假设真实值
y_true = np.array([1.0])

# 损失对输出层的梯度
loss_grad = y_pred - y_true         # MSE 的梯度简化版

# 反向传播到第二层参数
W2_grad = loss_grad * h             # 损失对 W2 的梯度（形状：(1,) * (2,) → (2,)）
b2_grad = loss_grad                 # 损失对 b2 的梯度（形状：(1,)）

# 注：这里 loss_grad 是标量（1,），h 是 2 维向量。
#      loss_grad * h 得到 (2,)，正好能广播到 W2 的 (1,2) 形状。
#      真实框架中会用 np.outer(loss_grad, h) 或 unsqueeze 保证维度严格匹配。

# 梯度继续往第一层传
h_grad = loss_grad * W2.flatten()   # 经过 W2 传回
h_grad[h <= 0] = 0                  # ReLU 的梯度：负数部分为 0

# 反向传播到第一层参数
W1_grad = np.outer(h_grad, x)       # 损失对 W1 的梯度
b1_grad = h_grad                    # 损失对 b1 的梯度

# 更新参数
W2 -= 0.01 * W2_grad
b2 -= 0.01 * b2_grad
W1 -= 0.01 * W1_grad
b1 -= 0.01 * b1_grad
```

这里的关键模式：

```text
前向：x → ... → h → y_pred → loss
反向：loss_grad → h_grad → W1_grad
```

每一层反向传播都只做三件事：
1. 接收上一层传来的梯度
2. 计算当前层参数的梯度
3. 把梯度继续传给下一层

## 六、复杂度与边界

1. **反向传播需要存储中间结果**
   - 前向计算时的中间值（h、激活值等）必须保留，反向传播才能用
   - 这就是为什么训练比推理需要更多显存

2. **梯度消失和梯度爆炸**
   - 层数太多时，梯度可能变得极小（消失）或极大（爆炸）
   - 这是为什么需要有归一化层（LayerNorm、BatchNorm）

3. **学习率必须合适**
   - 太大不收敛，太小太慢
   - 实践中常用学习率调度器（learning rate scheduler）

4. **梯度是近似，不是精确值**
   - 每个 batch 的梯度只是真实梯度的估计
   - 随机梯度下降（SGD）的"随机"就来自这里

## 七、论文与真实系统映射

这一章的基础概念是所有训练论文的底层语言。

- InstructGPT、LoRA、DPO 等论文中每次提到"参数更新"，本质都是梯度下降
- 所有优化器（Adam、SGD、Adagrad）都是梯度下降的变体
- 所有训练效率论文（如 FlashAttention、ZeRO）都在优化前向+反向的内存和计算

在真实系统里：
- 训练框架（PyTorch、TensorFlow）自动处理反向传播
- 但理解梯度是理解"为什么参数能调"的第一步
- 如果你去看 LoRA 论文，它在做的就是"只对部分参数计算梯度"
