## 三、直觉方案为什么不够好

很多人第一次接触"模型输出"时，直觉是：

> 直接拿输出向量作为"分数"，分数最高的就是答案。

这个直觉有两个问题：

**问题 1：分数不是概率，无法直接衡量"把握"**
logits 只反映相对倾向，不是一个 0~1 的、可解释的"把握程度"。我们想要一个满足"所有候选概率 ≥ 0 且总和 = 1"的分布，而不是一串任意幅度的数字。

**问题 2：分数不能直接用于训练**
训练需要一个"衡量模型分布和真实分布差距"的损失函数。而交叉熵作用的对象必须是概率分布，而不是 logits。

所以必须把输出向量转成概率分布。

## 四、正式机制

### 1. 输出向量 → 分数（logits）

神经网络的最后一层通常输出一个向量，每个元素对应一个候选词。

这个向量叫 **logits（分数）**。

```text
假设词汇表有 5 个词：["猫", "狗", "鱼", "鸟", "鼠"]
模型输出 logits：[2.0, 0.5, 1.2, -0.3, 0.8]
```

分数越高，模型越"倾向"这个词。

### 2. 分数 → 概率（softmax）

Softmax 把分数转成概率分布：

```python
import math

def softmax(logits):
    exp_logits = [math.exp(x) for x in logits]
    total = sum(exp_logits)
    return [x / total for x in exp_logits]

logits = [2.0, 0.5, 1.2, -0.3, 0.8]
probs = softmax(logits)
print(probs)
# 输出：[0.48, 0.11, 0.22, 0.05, 0.15]
```

Softmax 做了两件事：
1. 指数运算：把所有分数变成正数
2. 归一化：除以总和，让所有概率加起来 = 1

### 3. Softmax 的梯度特性

Softmax 有一个特别适合训练的特性：

> 如果正确答案的概率很低，softmax 的梯度会很大。
> 如果正确答案的概率已经很高，梯度会变小。

这意味着：模型会自动把训练精力集中在"还没学会"的样本上。

### 4. 交叉熵损失：衡量分布差距

交叉熵衡量"模型预测分布"和"真实分布"之间的差距。

对于语言模型，真实分布通常是"正确答案"的独热编码：
- 正确答案的位置 = 1
- 其他位置 = 0

交叉熵公式：

```text
CE = -log(p_correct)
```

- p_correct = 模型对正确答案预测的概率
- 如果 p_correct 接近 1：CE 接近 0
- 如果 p_correct 接近 0：CE 接近无穷大

### 5. 语言模型训练目标

语言模型训练的目标是：

> 在训练数据上，让所有 token 的交叉熵平均值最小化。

具体来说：
- 给定一段文本 "今天天气很好"
- 模型依次预测每个 token
- 对每个 token 计算交叉熵
- 对所有 token 的交叉熵取平均
- 用梯度下降更新参数

### 6. 困惑度（Perplexity）

困惑度 = 交叉熵的指数形式：

```text
PPL = exp(CE)
```

- 困惑度越低，模型越好
- 困惑度 = 10 意味着：模型平均来看，每次预测有 10 个候选词需要犹豫

困惑度是语言模型最常用的评测指标之一。

## 五、最小实现 / 伪代码

### 1. 完整的单步训练

```python
import math

# 词汇表
vocab = ["猫", "狗", "鱼", "鸟", "鼠"]

# 模型输出 logits（模拟）
logits = [2.0, 0.5, 1.2, -0.3, 0.8]

# 正确答案的索引（假设正确答案是"猫"，索引 0）
correct_index = 0

# softmax 转概率
probs = softmax(logits)

# 交叉熵
ce = -math.log(probs[correct_index])

# 梯度（简化的交叉熵对 logits 的梯度）
grad_logits = [p for p in probs]  # 复制概率
grad_logits[correct_index] -= 1   # 正确答案位置减 1

print(f"预测概率：{probs}")
print(f"交叉熵：{ce:.4f}")
print(f"logits 梯度：{grad_logits}")
```

这里的关键是 `grad_logits`：
- 正确答案的梯度 = prob - 1
- 错误答案的梯度 = prob

这意味着：正确答案的梯度是负的，错误答案的梯度是正的。
模型会提高正确答案的分数，降低错误答案的分数。

### 2. 模拟语言模型训练目标

```python
# 假设文本："今天天气很好"
# 模型依次预测每个 token

tokens = ["今天", "天气", "很好"]
total_ce = 0

for i in range(len(tokens) - 1):
    # 输入当前 token，预测下一个
    # 模拟 logits 输出
    logits = [1.5, 0.3, 0.8]  # 实际来自模型
    correct_index = 1          # 假设正确答案是索引 1

    probs = softmax(logits)
    ce = -math.log(probs[correct_index])
    total_ce += ce

avg_ce = total_ce / (len(tokens) - 1)
ppl = math.exp(avg_ce)

print(f"平均交叉熵：{avg_ce:.4f}")
print(f"困惑度：{ppl:.2f}")
```

## 六、复杂度与边界

1. **Softmax 是计算密集点**
   - 需要对每个候选词计算指数并归一化
   - 词汇表越大，softmax 的计算和显存需求越高
   - 现代 LLM 通常仍对整个词表做 softmax + cross-entropy；分层 softmax、负采样、采样 softmax 等是降低词表维度压力的近似手段，各有取舍

2. **交叉熵只关心正确答案**
   - 它不惩罚"错误答案"的分布形态
   - 这是它的简单之处，也是它的局限

3. **困惑度不能等价于真实能力**
   - 困惑度低 ≠ 模型在真实任务上表现好
   - 这只是"预测下一个 token"的能力，不代表"理解"能力

4. **标签平滑**
   - 真实分布有时不完全是独热编码
   - 标签平滑（label smoothing）可以防止模型过于自信

## 七、论文与真实系统映射

交叉熵 + softmax 是几乎所有语言模型训练的标配。

- GPT-3、InstructGPT、LLaMA 等模型都使用交叉熵损失
- 所有开源模型（如 Mistral、DeepSeek）的训练目标都是"最小化交叉熵"
- 困惑度是论文中常见的评测指标之一

在真实系统里：
- 完成判定不能只看困惑度
- 一个困惑度很低的模型，也可能产生不符合事实的输出
- 这就是为什么需要独立审查器、验证证据等机制
