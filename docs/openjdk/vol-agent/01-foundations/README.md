# 01 · 数学与学习基础

> 目标：补足理解神经网络、Transformer 和 Agent 所需的最小数学与学习理论。

## 章节规划

1. AI 系统的最小地图
2. 向量、矩阵与神经网络
3. 梯度下降与反向传播
4. 概率、交叉熵与语言建模
5. 信息论：熵、KL 散度与互信息
6. 数值稳定性：Softmax、LogSumExp 与混合精度
7. 优化器、正则化与训练稳定性
8. 统计学习：泛化、校准与分布偏移
9. 训练损失为什么不等于真实能力

## 阅读目标

读完本组后，应该能解释：
- 一个 token 如何从离散符号变成可训练的向量；
- 神经网络如何通过前向计算产生输出；
- 梯度如何从损失反向传播到参数；
- 为什么交叉熵适合语言模型训练；
- 训练、验证、泛化和过拟合分别意味着什么。
