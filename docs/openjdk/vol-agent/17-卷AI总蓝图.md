# 卷 AI 总蓝图

> 定位：这是卷 AI 做“系统性教材”的治理文档，不是正文。
> 目的：回答卷 AI 由哪些线组成、各线职责、读者怎么进入、写作按什么节奏长。
> 关联：`10-理论学习方法论.md`、`13-零基础阅读协议与学习进度卡.md`、`12-理论卷覆盖矩阵与收口标准.md`

---

## 一、总目标

卷 AI 不是“AI 名词词典”，也不是“论文收藏夹”，而是：

> 一套可以像 JVM 卷一样连续阅读、可验证、可扩展的 **AI / 大模型 / Agent 教材**。

它要同时回答三类问题：

1. **机制问题**：这个机制是什么，为什么需要它，没有它会怎样失败？
2. **证据问题**：提出它的论文/技术报告原始到底说了什么，结论边界在哪？
3. **工程问题**：它在真实 Agent / LLM 系统里最终怎么落地、怎么失败、怎么恢复？

一句话：

```text
理论负责讲懂
论文负责举证
实验负责验证
源码负责落地
```

## 二、四轨结构

卷 AI 由四条相互配合的轨道组成，不互相替代。

### 1. 理论主线
- **作用**：从零开始讲清概念、数学、机制、工程边界。
- **地位**：真正的教材正文，类似于 `vol-02` 的主线。
- **目录**：
  - `00-prerequisites`
  - `01-foundations`
  - `02-transformer`
  - `03-model-training`
  - `04-inference`
  - `05-agent-foundations`
  - `06-agent-runtime`
  - `09-safety-evaluation`
- **交付**：每篇正文按统一 8 段结构。

### 2. 论文主线
- **作用**：提供原始创新来源、实验设计、结论边界。
- **地位**：证据线，不替代理论主线。
- **目录**：
  - `07-papers`
- **交付**：每篇按统一论文精读结构；同时提供公开链接、本地 PDF、兴趣分级。

### 3. 实验主线
- **作用**：把公式、机制、运行时不变量变成可运行最小实验。
- **地位**：验证线，确保“会讲也会跑”。
- **目录**：
  - `08-labs`
- **交付**：每篇按统一实验结构，并记录能证明什么、不能证明什么。

### 4. 源码映射线
- **作用**：把理论/论文中的机制接到真实 Agent Runtime 源码。
- **地位**：落地线。
- **目录**：
  - 现有 `vol-agent` 根目录的五项目源码分析
  - `06-agent-runtime`
- **交付**：每个核心主题都应有一节“真实系统怎么实现”。

## 三、读者入口

### 完全零基础读者
推荐路径：`A → B → C → D/E`

```text
A 零基础桥：00-prerequisites
B 模型基础：01-foundations → 02-transformer → 03-model-training → 04-inference
C Agent 主线：05-agent-foundations → 06-agent-runtime → 09-safety-evaluation
D 证据与材料：07-papers
E 动手验证：08-labs
```

### 已有编程经验、想快速进入 Agent 的读者
推荐路径：
1. 先自测 `13-零基础阅读协议与学习进度卡.md` 的依赖门
2. 从 `02-transformer` 入手
3. 跟打 `05-agent-foundations`
4. 用 `07-papers` 的 ReAct / RAG / Tree of Thoughts 补证据
5. 用 `08-labs` 的 Tool Loop 验证

### 只关心真实源码的读者
推荐路径：
1. 直接进 `vol-agent` 现有五项目源码卷
2. 遇到不熟悉的机制，回 `02-transformer` / `04-inference` / `05-agent-foundations`
3. 再用 `07-papers` / `08-labs` 补证据与实验

### 在读论文的读者
推荐路径：
1. 先读 `07-papers/00-如何精读一篇AI论文.md`
2. 按 `07-papers/03-论文分级表.md` 选择入口
3. 每篇结束后回顾 `当前主题在理论线/实验线/源码线上对应什么`

## 四、主题四层写法

每个核心主题必须按四层推进，不能只写其中一层：

| 层 | 回答 | 主要产出 |
|---|---|---|
| 概念层 | 解决什么问题、最小前置、错误直觉 | 正文开头 |
| 机制层 | 对象、状态、数据流、公式、复杂度 | 正文中段、实验 |
| 证据层 | 谁提出的、用什么实验支持、局限 | 论文精读 |
| 工程层 | 真实系统怎么实现、失败怎么恢复 | 源码映射 |

## 五、推荐写作节奏

不并行乱开坑，按最小闭环推进：

### 阶段 A：模型最小闭环
- 00-prerequisites
- 01-foundations
- 02-transformer
- 配套：Attention 论文 / 最小 tokenizer+attention 实验
- 验收：读者能把 token 追踪到 logits。

### 阶段 B：训练与推理闭环
- 03-model-training
- 04-inference
- 配套：InstructGPT / LoRA / QLoRA / FlashAttention / Mistral
- 配套：KV Cache / sampling / quantization 实验
- 验收：读者理解能力怎么训练、请求怎么跑起来。

### 阶段 C：Agent 最小闭环
- 05-agent-foundations
- 配套：ReAct / Toolformer / RAG / Tree of Thoughts
- 配套：Tool Loop / RAG / Planner 最小实验
- 验收：读者理解模型为什么能变成 Agent。

### 阶段 D：Runtime 与可靠性闭环
- 06-agent-runtime
- 09-safety-evaluation
- 配套：现有五项目源码卷、完成判定/副作用/真相层专题
- 验收：读者理解 Agent 为什么不是 while(true) 调模型。

## 七、一句话结论

> 卷 AI 的成功标准，不是覆盖多少论文或名词，而是形成四条线：理论讲懂、论文举证、实验验证、源码落地。先建立模型最小闭环，再进入训练/推理、Agent、Runtime 与可靠性。
