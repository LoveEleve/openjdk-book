# 03 · 训练、对齐与模型能力

> 目标：解释基础模型能力如何被训练出来，以及预训练模型如何变成可用助手。

## 章节规划

1. 数据清洗、去重与数据配比
2. 预训练、权重与 Checkpoint
3. SFT：从续写模型到指令模型
4. RLHF：奖励模型与策略优化
5. DPO：直接偏好优化
6. 对齐、拒答与安全行为
7. Scaling Laws 与数据/参数/计算预算
8. 分布式训练：数据并行、张量并行与流水线并行
9. MoE：稀疏专家与路由
10. LoRA 与参数高效微调

## 阅读目标

读完本组后，应该能解释：
- 预训练目标如何塑造语言模型能力；
- SFT 和偏好优化分别改变什么；
- 为什么模型能力、助手行为和安全边界不是同一个概念；
- MoE、LoRA 等技术分别在计算和参数层面解决什么问题。
