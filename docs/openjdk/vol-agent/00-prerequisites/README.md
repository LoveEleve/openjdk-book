# 00 · 零基础前置：从程序、数据到“模型”

> 目标：不假设读者已经学过人工智能、机器学习、线性代数或深度学习，从最基本的计算机概念开始，逐步建立阅读后续章节所需的语言。

## 这一层解决什么问题

很多 AI 教程一开始就讲：
- 向量；
- 矩阵；
- 梯度；
- Tensor；
- Attention；
- Embedding。

但零基础读者真正卡住的地方往往更早：
- 什么是输入、输出和状态？
- 什么是函数？
- 数据为什么可以表示成数字？
- 程序和模型有什么区别？
- 参数、配置和训练出来的权重有什么区别？
- “预测”到底是什么意思？

本层先解决这些问题，不急着出现 Transformer、Loss 或 Agent 等高级术语。

## 章节规划

### 00-1 计算机到底在做什么

- 数据、指令、程序和状态；
- CPU、内存、磁盘和网络的基本角色；
- 输入、处理、输出；
- 为什么同一个程序换输入会产生不同结果。

### 00-2 从数字、文本到结构化数据

- bit、byte、整数、浮点数；
- 字符、编码和 Unicode；
- 文本、列表、字典、表格和 JSON；
- 为什么机器不能直接“理解文字”。

### 00-3 什么是函数和算法

- 函数：输入如何变成输出；
- 算法：有限步骤解决问题；
- 确定性程序和随机程序；
- 时间复杂度与空间复杂度的直觉。

### 00-4 什么是 Python 程序

- 变量、函数、循环、条件和异常；
- 模块、包和虚拟环境；
- 读取文件、调用函数和保存结果；
- 如何运行一个可重复的小实验。

### 00-5 什么是数据集

- 样本、特征、标签和目标；
- 训练集、验证集、测试集；
- 数据分布和数据泄漏；
- 为什么数据质量决定模型上限。

### 00-6 什么是模型

- 规则程序和参数化模型；
- 参数、权重、配置和状态；
- 模型预测与真实答案；
- 训练前、训练中、训练后的区别。

### 00-7 什么是学习

- 从样本中寻找可复用规律；
- 预测、误差和改进；
- 训练不是“把答案写进模型”；
- 泛化：模型如何处理没见过的输入。

### 00-8 从分类到生成

- 分类：在候选类别中选择；
- 回归：预测连续数值；
- 生成：一步一步产生下一个符号；
- 语言模型为什么可以被理解成“预测下一个 token”。

### 00-9 从答案到概率分布

- 确定性答案与概率预测；
- 候选输出、分数、概率和选择；
- 为什么模型不是直接吐出“唯一答案”；
- 预测分布如何支持采样和不确定性。

### 00-10 什么是 AI、机器学习和深度学习

- AI 是问题范围，机器学习是方法族，深度学习是模型族；
- 神经网络为什么只是参数化函数；
- 传统程序、机器学习模型、大语言模型的边界；
- 训练能力与运行时能力的区别。

### 00-11 经典机器学习的最小桥

- 线性回归、逻辑回归和决策树分别在做什么；
- 特征、参数、损失和决策边界如何对应；
- 监督学习、无监督学习和强化学习的区别；
- 为什么深度学习不是脱离机器学习的另一门学科。

### 00-12 如何阅读一篇 AI 文章或论文

- 它要解决什么问题？
- 输入、输出和评价指标是什么？
- 训练阶段和推理阶段分别做什么？
- 结论由什么实验支持？
- 哪些内容是事实，哪些内容是作者解释，哪些内容是我们的迁移判断？

## 最小实践

1. 写一个读取 JSON 并统计字段的 Python 程序；
2. 写一个根据规则分类的程序；
3. 用一组样本统计准确率；
4. 写一个“预测下一个字符”的最小程序；
5. 对同一个问题分别写规则程序和参数化模型的伪代码；
6. 记录训练集/测试集不同造成的结果变化。

## 进入下一层的标准

读者能够用自己的话解释：

- 数据和程序有什么区别；
- 函数、算法和模型有什么区别；
- 参数为什么可以被训练；
- 训练和推理分别是什么意思；
- 为什么生成模型可以拆成连续的“预测下一个 token”；
- 为什么模型输出不能自动等同于事实。

## 不在这一层深入

- 不提前讲 Attention；
- 不提前讲反向传播公式；
- 不提前讲 Transformer block；
- 不把 Python 语法写成完整语言教程；
- 不假设读者已经理解向量和矩阵。

## 一句话结论

> **在学习模型如何学习之前，先理解程序如何处理数据、函数如何产生输出、模型为什么是一种参数化函数。**
