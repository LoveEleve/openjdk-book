# 先读这一篇：怎样阅读这卷 Redis 源码分析

> 本文是卷级导读，回答这卷到底在讲什么、为什么这样排、每篇解决哪个读者问题。

## 这卷不是 Redis 配置手册

这卷真正要建立的是 **从类型系统到生产排障的完整 Redis 内部实现主线**。30 篇正文按 8 层组织，覆盖数据结构、事件驱动、命令执行、持久化、复制、高可用、生产排障和高级特性。

## 推荐阅读路线

### 第一阶段：数据结构与编码（7 篇）

R-1 redisObject → R-4 SDS → R-3 Dict → R-5 List → R-6 ZSet → R-7 Set → R-10 Stream

先建立 Redis 的类型系统，再逐层展开各数据结构的编码设计。

### 第二阶段：事件驱动（1 篇）

R-2 事件驱动 + IO 多线程

理解 aeMain 三阶段循环和 IO 多线程两阶段并行。

### 第三阶段：命令执行基础设施（3 篇）

R-25 缓冲区 → R-26 命令执行全流程 → R-27 Lua 脚本原子性

从"数据怎么进出"到"命令怎么穿过"再到"逻辑怎么扩展"。

### 第四阶段：经典混淆补深（5 篇）

R-29 键空间 → R-28 内存淘汰 → R-30 阻塞命令 → R-31 发布订阅 → R-32 ACL

面试高频且容易混淆的五组主题，每篇都直面易混淆点。

### 第五阶段：持久化、复制、高可用（5 篇）

R-11/12/13 编码专题 → R-8 持久化 → R-9 复制 → R-14 Sentinel → R-15 Cluster

### 第六阶段：生产排障（6 篇）

R-19~R-24：RDB 阻塞、大 key、backlog 溢出、AOF fsync、过期删除、慢命令

面试重难点，覆盖 Redis 线上最常踩的坑。

### 第七阶段：高级特性（3 篇）

R-16 事务 → R-17 tracking → R-18 defrag

## 每篇的结构

每篇包含四个文件：

1. `rewrite-plan.md`：写作规划，包含读者问题、主结论、结构设计、必须回填的源码锚点
2. `.md`（正文）：源码分析正文，问题→挣扎→顿悟→分层拆解→收网→下篇桥接
3. `.note.md`：本篇主张、边界、下篇桥接
4. `.review-notes.md`：六层审查笔记

## 如果你想快速了解

只读每篇的 `.note.md`，它包含本篇的核心主张和边界。

## 如果你想深入源码

读每篇的正文 `.md`，它包含完整的源码分析和锚点引用。
