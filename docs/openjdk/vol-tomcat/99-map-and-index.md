# Tomcat 卷总图 / 总索引

> 这不是新的正文专题，而是整卷导航图。它解决的不是“某个机制怎么实现”，而是：**如果你现在带着某个问题进来，应该先读哪几篇；如果你想回看某条主线，它在整卷里是怎么分布的。**

## 一、整卷主图：嵌入式 Tomcat 这一生

如果把整卷压缩成一张总图，它其实讲的是一台嵌入式容器的一生：

```text
装起来
  -> 跑起来
    -> 选目标 / 执行
      -> 偏离后重收束
        -> 管状态
          -> 管类空间与退场
            -> 暴露给 Spring Boot
              -> 校准规范边界
                -> 补深关键机制
                  -> 投影到生产性能 / 运维 / 故障
```

对应篇章：

- 装起来：`Ch1`、`Ch7`
- 跑起来：`Ch2`
- 选目标 / 执行：`Ch3`、`Ch6`
- 偏离后重收束：`Ch4`
- 管状态：`Ch5`
- 管类空间与退场：`Ch10`、`Ch11`
- 校准规范边界：`Ch8`
- 补深关键机制：`Ch9`、`Ch15`、`Ch16`、`Ch17`、`Ch18`、`Ch19`
- 投影到生产：`Ch12`、`Ch13`、`Ch14`

## 二、如果你是第一次看这卷，建议主线顺序

1. `Ch1` 启动与装配

## 五、篇章之间最关键的桥

- `Ch1 -> Ch2`
  - 容器怎么被装起来，下一步就是请求怎么进来

- `Ch2 -> Ch3`
  - 请求进到 Catalina 之后，怎么从路由走到执行链

- `Ch3 -> Ch4`
  - 正常执行链立住后，再看偏离主线怎么被重新接住

- `Ch4 -> Ch5`
  - 偏离主线讲完，再看长期状态是怎么活着的

- `Ch5 -> Ch6`
  - 状态链之后，回头看目标选择为什么要有独立路由树

- `Ch6 -> Ch7 -> Ch8`
  - 先讲 Tomcat 自己怎么做，再讲 Boot 怎么把它装起来，最后回头校准规范边界

- `Ch8 -> Ch9 -> Ch10/11`
  - 规范边界立住后，先深挖 Servlet 生命周期，再下沉到类空间与退场链

- `Ch15/16/17/18/19`
  - 这些是把主干里一笔带过但实际很重要的运行时机制再压实一遍

- `Ch12/13/14`
  - 这些不是附录，而是把整卷前文重新投影到生产世界里

## 六、最容易读散的地方

### 1. 直接从 Ch12 / Ch13 / Ch14 开始
可以读，但没有主干地图时，你会把它们误读成经验手册。

### 2. 只挑 `StandardWrapper`、`Http11Processor`、`TaskQueue` 这种类看
会知道一些细节，但拼不出整条系统主线。

### 3. 跳过 `Ch7` 和 `Ch8`
这样你会知道 Tomcat 当前怎么实现，却不知道：
- 真实项目里它是怎么被装起来的
- 哪些行为是规范要求，哪些只是当前实现

### 4. 把 `Ch10` / `Ch11` 当成 JVM 类加载通识去读
这两篇其实讲的是容器里的应用类空间生命史，而不是通用 JVM 教程。
