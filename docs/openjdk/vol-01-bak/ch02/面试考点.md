# ch02 面试考点

> 本文是 [ch02 JavaMain](../ch02.md) 的面试配套，不索引到书籍目录。

## Q1：`InitializeJVM` 做了哪些事？

三件事：(1) 把 `JLI_Launch` 累积的 `options` 数组组装成 `JavaVMInitArgs` 结构体（JNI 规范定义，含版本号 + 选项数组 + 是否忽略未知选项）；(2) 调用 `ifn->CreateJavaVM()`——这是 ch01 里 `dlsym` 解析出的函数指针，实际指向 `jni.cpp` 里的 `JNI_CreateJavaVM`；(3) 调用 `JNI_MemFree(options)` 释放不再需要的选项数组内存。返回 `JNI_OK` 表示 JVM 创建成功。

## Q2：`JavaMain` 的 10 个阶段中，哪些是"正常模式"必须走的，哪些是"快速通道"？

阶段 1-2 是所有模式都走的（解包参数 + 创建 JVM）。阶段 3-4 是快速通道——`-version`/`-help`/`--list-modules` 走完就从 `LEAVE()` 退出，不加载类。只有正常启动类/jar 时才会走到阶段 6-10（加载类 → 构建 args → 调 main()）。阶段 5（追踪日志）只在开启 `-Xdiag` 时才触发。

## Q3：`CHECK_EXCEPTION_LEAVE(n)` 和 `LEAVE()` 有什么区别？

`CHECK_EXCEPTION_LEAVE(n)` 是条件退——检查 JNI 环境里有没有挂起的异常，有就设返回码 `n` 并调用 `LEAVE()`。`LEAVE()` 是无条件退——做 `DetachCurrentThread` + `DestroyJavaVM` 后直接返回。正常控制流先检查异常（`CHECK_EXCEPTION_LEAVE`），确认没事才继续；正常完成后的退出（如 `-version` 打印完）直接用 `LEAVE()`。
