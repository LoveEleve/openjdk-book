# 第16章：interpreter_init —— Template Interpreter

> 本章讲解 HotSpot 为什么不用 switch-case 解释器，而是用 Template Interpreter——每个字节码生成一段独立的原生机器码（Codelet），存在 `StubQueue` 中。解释执行时直接跳转到对应 Codelet，没有 dispatch loop 的开销。
