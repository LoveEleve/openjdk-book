# 第14章：三个 Table 的初始化——SymbolTable / StringTable / ResolvedMethodTable

> 本章承接 `universe_init` 第⑩⑪步的三个 `create_table()` 调用。三张表都是哈希表，却因服务对象不同走了三条技术路线：SymbolTable 经典链表哈希（强引用，乐观锁）；StringTable 并发无锁哈希（弱引用，JDK 11 重写）；ResolvedMethodTable 经典表 + 弱引用（方法解析缓存）。锁模型由访问频率决定，引用模型由生命周期决定。

| 14.2 | [02-string-table-create.md](ch14/02-string-table-create.md) | StringTable 初始化：OopStorage 弱引用、ConcurrentHashTable 无锁读、渐进扩容 |
