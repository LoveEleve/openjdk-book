# 第18章：SharedRuntime::generate_stubs —— 共享运行时存根

> 本章讲解 `init_globals()` 第 123 行调用的 `SharedRuntime::generate_stubs()`——该函数在 CodeCache 中生成 12 个共享运行时存根（6 个 resolve stub + 3 个 safepoint handler + 1 个 deopt blob + 1 个 uncommon trap blob + 1 个 static call entry），为 JIT 编译代码与 VM 运行时之间的桥接提供基础设施。这些存根是"编译代码和 VM 运行时的中间人"——编译代码不能直接 call C++ 函数，必须通过存根做寄存器保存、帧转换、oop map 注册。
