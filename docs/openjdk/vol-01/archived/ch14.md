# 第14章：SymbolTable + StringTable + ResolvedMethodTable

> 本章承接 `universe_init` 中三个 Table 的 `create_table()` 调用，深入三者的内部结构、分配策略、锁模型和 GC 交互。三个 Table 看似都是"哈希表"，但内部实现差异巨大——SymbolTable 用固定大小 Hashtable + Arena，StringTable 用 ConcurrentHashTable + OopStorage weak handles，ResolvedMethodTable 用简单 Hashtable + ClassLoaderWeakHandle。
>
> 共 4 篇，按复杂度递增排列：SymbolTable（最基础）→ StringTable（最复杂）→ ResolvedMethodTable（最简单但有独特设计）→ CDS 差异 + 对比。
