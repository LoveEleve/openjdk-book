# 第12章：Metaspace 诊断与排查

> 本章是 ch10/07 Metaspace 背景知识的工程实践延伸。ch10/07 讲解了 Metaspace 的三层架构（VSL → ChunkManager → SpaceManager）、分配全路径、OccupancyMap 位图、split/coalesce 对偶机制和 purge 流程。本章是**维修手册**——运行时怎么观测这套机制？出问题了怎么修？
>
> 共 5 篇，按学习成本递增排列：零门槛通道（jstat + GC 日志）→ jcmd 全线 → NMT → JFR → 综合实战场景。每篇写完前用 MCP 验证关键结论。
>
> CDS 与 Metaspace 的交互不在本章——CDS 面试/生产使用率低，内容在 ch13 中完整展开。
