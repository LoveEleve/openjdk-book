# HikariCP Ch5-01 连接生命周期管理 / HouseKeeper — note

## 本篇主张

- 连接归还后生命史并未结束。maxLifetime（连接不能无限活着）、keepaliveTime（空闲连接仍在池的管理范围内）、idleTimeout（值不值得继续活）三个参数共同决定连接余生，而非独立配置项。
- HouseKeeper 是后台控制面执行者，承担时钟回拨检测、空闲淘汰、池填充等维护职责，不是普通定时线程。

## 本篇边界

- 不展开连接验证细节
- 不展开 JMX 与指标监控体系
