"**JarURLConnection**: java.net.JarURLConnection extends URLConnection. Handles URLs with 'jar:' scheme: `jar:<url>!/{entry}`. When opened, it opens the <url> as a ZipFile → locates the {entry} inside the ZIP → returns an InputStream for that entry. For nested JARs (jar:file:///outer.jar!/inner.jar!/), this requires recursive resolution — open outer JAR → locate inner.jar entry → open inner JAR → locate target entry."
