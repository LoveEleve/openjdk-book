## Fix 1: 06-OopMap-GC-Roots.md §四.1 — add bitmask vs list comparison

Find the paragraph discussing OopMap size (~10 bytes/safepoint). After it, add:

"A simple list encoding: each oop = 4 bytes (2B register/slot index + 2B type encoding) → 5 oops per safepoint = 20 bytes. Bitmask: delta-compressed offsets → ~2 bytes per oop → 5 oops = ~10 bytes. With 15,000 nmethods × avg 5 safepoints each = 75,000 OopMaps × 10 bytes saved = 750KB CodeCache savings. This is why HotSpot chose bitmask over list — it's a small difference per OopMap, but at JVM scale (millions of OopMaps), it matters."
